# Security Policy

This repository is primarily documentation and examples. Still, security issues can appear in example code, automation, or published guidance.

## Reporting

Please do not publish sensitive security issues in a public issue.

Send a private report to the maintainer with:

- Affected file or example.
- Steps to reproduce.
- Potential impact.
- Suggested fix, if known.

## Scope

In scope:

- Vulnerabilities in example code.
- Dangerous guidance that could cause credential leakage or unsafe automation.
- Supply-chain risks in project metadata.

Out of scope:

- General disagreements about AI coding style.
- Issues requiring access to private systems not owned by this project.
