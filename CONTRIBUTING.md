# Contributing

Thank you for helping improve this project.

## Good Contributions

- Better `AGENTS.md` templates.
- New language or framework examples.
- Clearer explanations of context engineering patterns.
- Research notes with citations.
- Tests or scripts that validate examples.

## Pull Request Checklist

- Keep the root `AGENTS.md` concise.
- Add or update a local `AGENTS.md` when introducing a new example folder.
- Run the example tests you changed.
- Explain how the change helps humans and AI agents work with the project.

## Documentation Guidelines

- Use concrete examples.
- Avoid broad claims without evidence.
- Mark speculation clearly.
- Prefer short, reviewable sections.

## Issue Reports

When opening an issue, include:

- What you expected.
- What was unclear or incorrect.
- The file or example involved.
- A suggested improvement, if you have one.
